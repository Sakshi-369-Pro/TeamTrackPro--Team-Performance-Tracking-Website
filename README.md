# 🚀 TeamTrack Pro

> **AI-Powered Team Performance & Project Intelligence Platform**

TeamTrack Pro is a modern full-stack project management platform designed to help organizations efficiently manage teams, monitor project progress, analyze employee performance, and streamline resume optimization through AI-ready features.

Built with scalability in mind, the platform combines project management, performance analytics, collaboration tools, and intelligent career assistance into a single application.

---

# 📌 Overview

Managing multiple teams and projects often becomes challenging due to scattered communication, poor task visibility, and the lack of performance insights. TeamTrack Pro addresses these challenges by providing a centralized workspace where managers and team members can collaborate effectively while leveraging AI-driven capabilities for smarter decision-making.

# 🚀 Getting Started

## Prerequisites

* npm
* Python 3.10+
* pip

---

## Frontend Setup

```bash
npm install
npm run dev
```

---

## Backend Setup

```bash
cd backend

pip install -r requirements.txt

uvicorn app.main:app --reload
```
